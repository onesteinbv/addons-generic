===========================
Website Sale Share Telegram
===========================

This module introduces a new share option in Product Share Website Snippet. The new option
is to share on Telegram.

Because Telegram can be deployed on any domain, this module uses the two-step
sharing functionality introduced by module 'website_two_steps_share_technical'.
